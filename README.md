# Yash Kanojia — Portfolio

Personal portfolio site for **Yash Kanojia**, a frontend developer based in New Delhi. Built to be fast, clean and easy to read on any device — no frameworks, no build step, just HTML, CSS and JavaScript.

**Live site:** https://kanojia-yash.github.io/portfolio/

## Built with

- HTML5
- CSS3 — custom properties, Grid & Flexbox, fluid type
- Vanilla JavaScript — no libraries, no dependencies

## Features

- Fully responsive, from small phones to wide laptop screens
- No animation libraries or heavy effects — just quick, purposeful transitions
- Plain three-file setup, no build tools or bundler required
- Accessible: semantic landmarks, visible focus states, skip-to-content link
- Contact form opens a pre-filled email or WhatsApp chat — no backend needed

## Project structure

```
portfolio/
├── index.html   # Page structure & content
├── style.css    # All styling
├── script.js    # Nav, scroll-spy & contact form logic
└── README.md
```

## Run it locally

Just open `index.html` in a browser, or serve it locally:

```bash
git clone https://github.com/kanojia-yash/portfolio.git
cd portfolio
python -m http.server 8000
```

Then visit `http://localhost:8000`.
